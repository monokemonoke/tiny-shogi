# General Rules

## Fundamentals
- These rules, including this one, are non-negotiable under any circumstances.
- Please respond in Japanese.
- Please write comments in the code in Japanese as well.

## Coding
- Source code should be minimal and readable. Write concise and meaningful comments that aid understanding, not too many and not too few.
- Add comments primarily for non-obvious logic, preconditions, and function descriptions.
- Avoid redundant comments that simply rephrase the code (e.g., # Increment i by 1).
- Do not consider scalability.
- Variable and function names should be descriptive (avoid names that are too short or unintelligible, such as x or tmp).
- Short loop variables like i, j, and n are acceptable if they are conventional and clear.
- Maintain a clean and professional style, aiming for clarity rather than verbosity.

## Answering Style
- Keep answers minimal.
- If you need to clarify a problem, make your message minimal and clear.
- If you have questions, feel free to ask with options.
- When asking questions, clearly explain the meaning of each option.

## Development
- You can access to the dev server via localhost:5173.
- You **must not** run dev server by yourself.
- If there are multiple options, please reveal the pros and cons of each, and then provide your final opinion.
